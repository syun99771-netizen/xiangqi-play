# Exact KNK/KNKA root guidance, 2026-11-11

This project's generated distance table covers red king and knight against black king with zero or one advisor. It is not a neural model, a replacement referee, a general endgame tablebase, or a native backend. The table contains 87,480 byte slots. 53,736 legal diagrams and 268,296 transitions were enumerated; 52,752 slots have finite proven red-win distance. Unknown/invalid entries do not guide. No symmetry or ordinary-game reachability is assumed.

Reproduce every byte using `node scripts/verify-endgame-table.mjs`. The script enumerates the graph, performs retrograde analysis, checks all Bellman distances and compares the embedded table. Independent research additionally compared all 53,736 legal move sets with a pinned official-source native Fairy executable (NNUE disabled), checked 108 terminal public outcomes and proof closure, and audited all edges and indexes. Native binaries and experimental WASM code are not shipped. The native oracle is a test dependency only; these generated game facts are not copied native engine source.

Admission requires the existing validated complete chronological history, ongoing b562 root, exact material, red to move, finite positive distance, and raw halfmove plus distance strictly below 120. Every previous supported solved state of rank at most the root rank rejects guidance. This conservative exclusion ensures no possible strictly decreasing future proof path revisits supplied history. It does not reconstruct missing history. Unsupported, conflicting or near-clock cases keep the existing search. The existing public rules are not claimed to be full CCA certification.

Results explicitly carry status `proven-endgame`, source `knka-exact-v1`, remainingPlies, depth 0, score null, nodes 0 and no completed search iterations. The one-move PV is a certified choice, not an invented complete PV. Remaining plies are an upper bound against any legal defense while following guidance. They are not search depth. Fixed-depth requests can finish early on proof; infinite requests wait for the user's Stop action. Full model authentication and original history validation remain in place. Zero search nodes is not zero CPU time.

A selected 24-root conversion diagnostic showed 24 proven-guide wins in 15–33 plies versus 9 baseline wins and 15 games unfinished at the 64-ply cap. This is not an Elo estimate or a general strength study. The diagnostic was interrupted after 12 complete pairs and 42 plies of the next baseline game, then resumed from its preserved next decision; one unlogged in-flight call may have been recomputed. Completed prefixes were retained and all 48 games / 1,769 moves replay-verified. Do not describe this as an uninterrupted run or the unfinished games as draws.
